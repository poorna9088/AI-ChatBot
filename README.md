# AI ChatBot 

A full-stack AI chatbot built using Flask, JavaScript, and Groq API.

## Features
- AI Chat Responses
- Voice Assistant 
- Chat History Saving
- Modern Dark UI
- Typing Animation
- Responsive Design

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- Groq API

## How to Run

1. Clone the repository

git clone https://github.com/poorna9088/AI-ChatBot.git

2. Install requirements

pip install flask flask-cors groq python-dotenv

3. Add your API key in `.env`

GROQ_API_KEY=your_api_key

4. Run the app

python app.py
